# Part 3 - Makemore (MLP Language Model)

Andrej Karpathy의 [Building makemore Part 2: MLP](https://www.youtube.com/watch?v=TCH_1BHY58I&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=3) 영상을 보며 따라 구현한 실습 노트.

## 내용

- Bengio et al. (2003) 논문 기반 MLP 언어 모델 구현

### 구현
- 문자 임베딩(character embedding) 학습
- MLP로 다음 문자 예측
- 미니배치(mini-batch) 학습
- 학습률(learning rate) 튜닝
- 훈련/검증/테스트 데이터 분리 및 평가

- `mlp.ipynb` - 실습 노트북 (주석 및 노트 포함)
